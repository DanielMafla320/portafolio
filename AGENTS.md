# Project Guidelines

## Project Context
- This is a professional developer portfolio.
- Respect the installed versions of Next.js, React and TypeScript.
- Inspect package.json before changing dependencies.
- Read the relevant local Next.js documentation before writing code.

## UI/UX Design
- Create elegant, distinctive and professional interfaces.
- Avoid generic layouts and excessive repetitive cards.
- Maintain consistent typography, spacing, colors and visual hierarchy.
- Ensure responsive behavior on mobile, tablet and desktop.
- Follow accessibility best practices.
- Use subtle animations and respect reduced-motion preferences.

## Development Rules
- Inspect existing components before editing.
- Preserve the current architecture unless a change is necessary.
- Reuse components when appropriate.
- Avoid unnecessary dependencies and unrelated refactors.
- Do not invent projects, clients, experience or achievements.
- Run appropriate checks when possible and report actual results.

## Workflow
1. Inspect the relevant files and documentation.
2. Identify the problem and propose an approach.
3. Implement the requested changes.
4. Verify the result where possible.
5. Summarize changes and remaining issues.
